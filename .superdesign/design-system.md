## 0. 产品上下文

- **产品**：一个实验室（网络攻防与信息安全）的招新落地页 —— 单页、单文档、无路由。
- **受众**：本校大一大二学生，手机为主、桌面为辅；在群里被转发链接后 10 秒内决定是否报名。
- **JTBD**：① 了解四个方向（软件/硬件/算法/人工智能）→ ② 知道流程时间线（预热→报名→初筛面试→结果）
  → ③ 填报名表（9 个必填项 + 图形验证码）→ ④ 拿到一次性编辑码 → ⑤ 加群、看友链。
- **阶段驱动**：页面按 `warmup | signup | review | result` 四阶段切换文案与禁用态（服务端下发）。
- **技术**：原生 HTML/CSS/JS + Express 静态服务。无框架、无打包器、无 Tailwind、无组件库。
- **视觉母题**：VSCode 式编辑器/终端 —— 一条会"真的在打字"的代码带（背景层），
  内容以玻璃卡片压在它上面滑动。**这个母题是本页的差异化资产，必须保留。**

### 页面结构（顺序不可改）
`header.top`（玻璃条：标签页身份 + 阶段状态 + 4 个锚点 + 报名 CTA + 阅读进度线）
→ `#hero`（H1 + 导语 + 单个 CTA）
→ `#directions`（4 行"方向"，每行=中文名+序号+一行伪 diff + 说明，点行预填表单）
→ `#flow`（4 段流程时间线 + 公告列表）
→ `#apply`（文档面：报名表 9 必填 + 3 选填 + 验证码 + 提交 + 编辑码面板）
→ `#join`（二维码 + 7 天失效警告 + 友链卡片 + 页脚）

### 层级契约（不可压平）
| 层 | z-index | 说明 |
|---|---|---|
| `body::before` 氛围层 | 0 | fixed，铺满整页 |
| `.cf` 代码带 | 1 | fixed，`aria-hidden` 纯装饰；`contain: layout paint style` |
| `.page` 内容 | 2 | relative |
| `.top` 顶栏 / `.cf-hold` 暂停徽标 | 4 | sticky / fixed；**暂停徽标必须在 `.cf` 外面**（`.cf` 有 transform + contain，fixed 子元素会被困住） |

## 2. § B TARGET — Session（全场域会话）

一句话：**整块屏幕就是那台机器，内容是一张张压在它上面的文档页。**
保留编辑器母题与**真实打字引擎**，但把它从"页面上侧一条带子"升级为**整屏场域**，
并把内容从"玻璃卡片"改成**不透明文档页**。

### 2.1 与上一版（Graphite Console）的三处结构差异

| # | Graphite Console | Session（本版） | 为什么 |
|---|---|---|---|
| 1 | 代码带 = 上侧 46vh 的一条 | **整屏 fixed 场域**，径向遮罩只给四角收边 | 每一屏背后都是活的代码，而不是只有第一屏 |
| 2 | 玻璃卡片（blur 28px、tint .28、brightness .94） | **更薄的玻璃**（blur 20px / tint .46 / brightness **.84**），手机 14px | 卡片是「看背景的窗口」不是遮光板；厚度用 blur 换，不用 tint 堆。旧版提亮（.94）会把背后代码放大、把文字对比度打死 |
| 3 | 内容排在代码带旁边（不重叠） | **代码栏移到文档列下面，两栏重叠 ≈ 22vw** | 玻璃背后必须有东西可透。重叠的那截就是透过玻璃看到的代码 |

### 2.2 色板（唯一的颜色来源，不得新增色相）

```
--s-ground  #07090f   场域底（比编辑器灰更暗：语法色按亮底标定，底越暗对比度越高）
--s-surface #0d1119   文档页
--s-raise   #131926   块内抬升（面板头 / 输入框头 / 悬停态）
--s-sunken  #090c13   块内凹陷（表单底 / 公告 / 友链 / 二维码井）
--s-fg-0 #f2f5fa 17.2:1   --s-fg-1 #cbd2dd 12.4:1
--s-fg-2 #a8b2c0  8.4:1（实底）—— **玻璃上的下限档，不得再暗**
--s-fg-3 #7e8896  5.1:1（实底）—— 仅页脚这类装饰，不承载信息
--s-line-soft rgba(255,255,255,.07)   --s-line .12   --s-line-strong .22
--s-glass      rgba(13,17,25,.24)   文档页玻璃（薄）
--s-glass-deep rgba(9,12,19,.22)    玻璃里的凹陷面
--s-blur 16px（<700px 为 14px）
--s-accent #4da3e8（交互与状态，禁止装饰）  --s-fill #0078d4（状态栏填充，配白字 4.53:1）
--s-ink #06263f（亮蓝按钮上的深墨：#4da3e8 配白字只有 2.72:1，配深墨 5.9:1）
--s-add #4ec9b0 · --s-del #f48771（仅语义）
--dir-sw #4da3e8 · --dir-hw #e0a458 · --dir-al #c586e0 · --dir-ai #4ec9b0（仅方向标记）
```
**禁止**：紫/粉渐变、霓虹发光、彩色 bokeh、玻璃与模糊、第三个强调色、
以及把方向四色用作大面积背景。

### 2.3 表面：玻璃三档 + 实底两档

| 层级 | 表面 | 模糊 | 描边 |
|---|---|---|---|
| 顶栏 `.top` | `rgba(13,17,25,.52)` | `blur(16px) saturate(130%) brightness(.88)` | 底边 1px `--s-line-soft` |
| 文档页 `.shell` | `rgba(13,17,25,.24)` | `blur(16px) saturate(132%) brightness(.96)`（<700px：14px） | `--s-line-soft` + 内上高光 10% + `0 28px 64px -28px rgba(0,0,0,.92)` |
| 玻璃里的凹陷面（`.pane` / 公告 / 友链 / 二维码井 / 方向行） | `rgba(9,12,19,.22)` | 继承父级 | `--s-line-soft` |
| 输入框 | `--s-ground`（实底） | — | `--s-line`，聚焦转 `--s-accent` + 3px 18% 环 |
| 状态栏 | `--s-fill #0078d4`（实底） | — | 左分隔 `rgba(255,255,255,.22)` |
| 悬停 / 选中 | 该面抬亮到 `rgba(19,25,38,.74)` | — | `--s-line-strong` / `--s-accent` |

玻璃的三条硬规则（采像素量出来的，见 `contrast.js`）：

1. **blur 是透明度的杠杆，不是 tint。** 模糊把背后的亮峰摊平 → 同样的可读性下 tint 可以更低、
   代码透得更清楚。先加 blur，别先加不透明度。
2. **brightness 只能 < 1**（本页 .84–.88）。提亮会放大背后的代码、把文字对比度打死
   —— 旧版 `.94` 就是这么错的。
3. **弱文字有下限**：`--s-fg-2` 不得暗于 `#a8b2c0`（玻璃上最坏 8.1:1）。
   **玻璃会让「次级文字」这个层级变窄** —— 这是本设计里最容易翻车的地方。

**实底降级**：`@supports not (backdrop-filter: blur(1px))` 时 `.shell` / `.top` 退回 `--s-surface`。
半透明 + 背后跑代码 = 文字直接报废，宁可不透。
**性能**：玻璃面积越大越贵。手机断点把 blur 收到 14px；填表聚焦时引擎本来就会暂停；
`.cf` 保持 `contain: paint` + 独立合成层。

### 2.4 代码场域（科技感与"酷"的主要载体 —— 不得替换、不得静止化）

- **真实引擎**：`public/codefield.js` + `public/codefield-data.js` 原样运行。
  逐字打字（连击 + 停顿 + 3.5% 走神）、错字红色波浪线、整行重写、
  四套依赖拉取过渡（Maven / apt+make / pip / npx）、终端档流式输出 —— 全部保留。
- 位置：`position: fixed` 整屏；桌面端代码栏 `left:0 / right: clamp(40px,4vw,90px)`，
  **字号 15px**（比手机大一号 —— 它是壁纸，要大一点才盖得住卡片底下那块面积）；
  手机端满宽 13.5px。遮罩为**左上发散的径向渐隐，只给四角收边**（165% 130% at 6% 0%）。
- **代码必须在卡片下面**：这是玻璃成立的前提。文档列左右各露出一截清晰代码
  （左 ≈ 24vw 起是文档列，所以左边那一截是清晰的；卡片右缘之外是页边距）。
- 行号栏与代码之间 1px 竖发丝线（编辑器签名）。
- 面板头用 `❯` 提示符回显眉标（`h2-en`）；不要发明第二种提示符。
- **方向行 → 切档**：hover/focus 预览、click 定格并停自动轮播（真实行为，见 `public/app.js` §2）。
  状态栏左下角的 `❯ 文件名 · 语言` 读数是同一份数据。
- 填表聚焦 → 自动暂停 + 徽标（引擎自带，不得去掉）。

### 2.5 科技感 = 精密（四件套，不允许靠发光）

1. **行号语言**：小节标题前有 `01/02/03` 计数器，方向行有 `01–04` 行号栏，
   与编辑器共用同一套 gutter 宽度。
2. **发丝分隔**：面板头、列表行、文档页内分区一律 1px `--s-line-soft`，不用阴影、不用色块。
3. **读数化**：所有数字等宽 + `tabular-nums`（`--s-code`）；阶段用 6px 圆点 + 文本。
4. **动效克制**：零新增动效。只有 120ms 描边/底色过渡与 90ms 按压。
   所有"运动"都来自场域本身（打字），不来自装饰。

### 2.6 版面契约

```

### 2.9 实测记录（采像素；1440×900 与 390×844 各一遍）

**玻璃到底透出多少背景**（同一块卡片区域截两次：场域开着 / 把 `.cf` 藏掉）：

| | 卡片区域平均亮度 | 代码透过玻璃的贡献 |
|---|---|---|
| 桌面 1440 | L 0.00668 → 0.00742 | **+11%** |
| 手机 390 | L 0.00667 → 0.00909 | **+37%** |

桌面比手机低是因为卡片只有约 3/4 面积压在代码的「墨」上（代码行只有 40–70 字符宽），
手机是全宽压在墨上。**要更透的杠杆在这里**：`--s-glass-deep` 再降、`--s-blur` 再收，
代价是次级文字的余量。

**文字 vs 玻璃背后最亮像素**（20 行全部 ≥4.5:1，最低 5.51:1）：

| 层 | 实测最坏 |
|---|---|
| hero 标题 / 导语 | 18.1:1 / 12.9:1 |
| 区块标题（玻璃上） | 18.1:1 |
| `--s-fg-1` 表单标签（玻璃里的凹陷面） | 13.0:1 |
| `--s-fg-2` 方向说明（玻璃上，最紧） | **8.2:1** |
| `--s-fg-2` 提示 / 流程说明 / 必填读数 | 9.2 / 9.2 / 8.7:1 |
| `--s-fg-3` 页脚（装饰档） | 5.5:1 |
| 主按钮墨字 / 亮蓝底 | 5.7:1 |

#### 这一轮踩的两个坑（都会给出错误结论，值得记）

1. **探针把被测的东西自己也藏了。** 为了量「文字背后的背景」，第一版把
   `*{color:transparent}` 全设了 —— 而**代码本身就是文字**（`.cf-t` 的语法色靠 `.k-*` 类），
   于是代码也被藏掉，量到的是「玻璃盖在空底上」。表现是：把整层场域 `visibility:hidden`
   后数字**纹丝不动**。正确做法：只藏内容层（`.page *`），`.cf` 一个字都不能碰。
2. **特异性不足导致样式静默失效。** `codefield.css` 里是 `.cf-body.is-editor { top: var(--cf-top) }`
   （0,2,0），本层只写 `.cf-body`（0,1,0）盖不住 —— 代码顶到 y=30，被顶栏压掉一截。
   必须写 `.cf .cf-body`。**不量元素位置就看不出来。**

`verify-session.js` 同时断言：引擎在打字（可见 token 递增）、横向溢出 0、<44px 可点元素 0 个。

### 2.7 拇指区状态栏

fixed 底部 44px（+ `env(safe-area-inset-bottom)`），`--s-fill` 蓝底白字，等宽小字，从左到右：
`❯ 文件名 · 语言`（场域实时读数）→ 撑开 → `● 阶段`（`#phase-text` 唯一实例，从顶栏搬来）
→ `加群` → `报名`（高亮块）。三个读数都是真实状态，不是装饰。

### 2.8 明色主题

本轮**只做深色**。浅色主题要单独设一轮（令牌镜像关系见 `themes/*.css` 顶部）。

## 3. 硬约束（两个区块都适用）

- **排版**：只用 `--font-ui` / `--font-code` 两个系统字体栈，禁止引入任何 webfont。
- **表单可用性**：`--fs-input` ≥ 16px（低于此 iOS 聚焦会缩放整页）；输入框、textarea 的
  `maxlength` 与校验文案不变。
- **无障碍**：装饰层（代码带、序号、进度条、角标）`aria-hidden`；任何可视化读数都必须有等价文本；
  `prefers-reduced-motion` 下动效全停且内容呈终态；`:focus-visible` 必须有可见焦点环
  （`outline: 2px solid var(--s-accent)`）；可点元素 ≥44px。
- **打印**：不显示代码带、氛围层与状态栏。
- **中国语文案全部保留**（结构与措辞都是产品决策，不要改写、不要翻译、不要精简）。
- **不加新功能**：不加导航、不加开关、不加装饰性图形、不改区块顺序。
- **HTML 契约**：每张草稿是**一个完整文档**（`<!DOCTYPE html>…</html>`），`<body>` 无 class，
  布局挂在一个根 `<div>` 上；`<a>` 必须有唯一 `id`；链接只用 `https://` 绝对地址或 `#锚点`，
  禁止相对路径（`src="/…"` 必须换成 `data:` 或公开 URL）。

## 4. 草稿的拼装方式（本页特有，别的项目不适用）

本页的差异化资产是**真在打字的引擎**，任何"画一个像代码的背景"的做法都会丢掉它。
所以草稿不是让设计模型凭上下文画一张，而是**用真实代码拼装**：

```
.superdesign/tmp/parts.json         Playwright 从运行中的站点抓的真实 DOM（终态）
  + themes/02-editor-dark.css       真实令牌（语法色 / 编辑器界面色）
  + public/codefield.css            真实场域样式
  + .superdesign/drafts/session.css 本轮的设计层（**唯一新写的东西**）
  + public/codefield.js / -data.js  **内联** → 画布上就地打字
  = .superdesign/drafts/03-session.html  → import-design-draft
```

配套脚本（都放 `.superdesign/drafts/`，输入在 `.superdesign/tmp/`，已 gitignore）：

| 脚本 | 作用 |
|---|---|
| `extract.js` | 跑起站点 → 抓真实 DOM / 锚点 id / 图片 → `tmp/parts.json`（源码改了要重跑） |
| `build-session.js` | 拼装上面的等式；顺带把 `#phase-text` 搬进状态栏、校验锚点 id 唯一 |
| `verify-session.js` | 真浏览器自检：引擎是否在打字、有无横向溢出、<44px 可点元素 |
| `contrast.js` | **采像素**量对比度（只藏文字、内缩 3px —— 见 §16 的两条教训） |

设计层的唯一真相是 `.superdesign/drafts/session.css`，它和 § B 必须一致。

## 5. 三个候选方向 D1 / D2 / D3（本轮，2026-09-12）

§ B（Session）用户**不满意**。诊断如下（据 frontend-design 的三条默认长相自查）：

| 问题 | 具体 |
|---|---|
| 还是「暗色控制台」 | 近黑底 + 单一亮强调色，是这个品类的默认长相；VSCode 暗色是最被模仿的开发者审美 |
| 版面还是模板骨架 | 内容柱 + 卡片，和 99% 的落地页同一副骨架；编辑器身份只作为背景纹理存在 |
| 序号是装饰 | 四个方向用了 01–04 行号 —— 但方向是一个**集合**，不是序列。只有流程才是序列 |
| 没有表达页面自己的论点 | 导语写着「攻击与防御，是同一门手艺」，而设计里没有任何地方能看出这件事 |

于是本轮给出三个**骨架不同**的方向（不是换皮）。三者共享：真实标记、真实场域引擎、
真实文案与表单、同一套机制层 `base.css`。差别 100% 在设计层。

| | 主张 | 大胆之处 / 风险 | 场域角色 |
|---|---|---|---|
| **D1 · 薄纸 TRACE** | 这个页面是一份**写在纸上的报告**，压在一直开着的机器上 | 风险：安全行业默认该是暗色，这里给了浅色报告。区分点：纸是 0.88 的透光纸，机器的暗与亮会透成会动的灰影；首页那块**证据窗**是全强度的活体 | 整屏背景 + 首页证据窗全强度 |
| **D2 · 警戒线 HAZARD** | 这个页面是**被围起来的现场** | 风险：墨黑 + 单一亮色。区分点：黄色只承担「分隔 / 标记 / 动作」三种语义（胶带 = 结构），轮换章节、标签、CTA、左侧固定胶带；正文一律骨白到灰 | 整屏背景 + 节间 12px 缝 + 带子内半透明 |
| **D3 · 扫描 SCAN** | 这个页面是**一次对实验室的扫描** | 风险：仪器感容易冷。区分点：四个方向是**活的扫描结果表**（指向哪一行，背后机器就切到那个文件），流程是编号节点 + 连接线（真序列），右侧竖排阶段轨道是服务端下发的真实状态 | 整屏背景 + 章节间 32px 缝 |

### 5.1 实测（采像素；1440×900 与 390×844）

### 5.2 层与脚本

```

### 5.3 三个方向的共同硬约束（不许破）

- 场域引擎原样运行，四个方向的文件与「方向行 → 切档」都在。
- **方向不编号**（集合，不是序列）；流程编号（真序列）。
- 所有中文文案、9 个表单字段、区块顺序不变。
- 文字对「背后最真实的那一个像素」≥4.5:1；可点元素 ≥44px。
